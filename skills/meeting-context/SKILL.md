# Meeting Context — контекст с групповых встреч

## Назначение

Сканирует конспекты в `~/Downloads/`, находит участие людей из `notes/teams/` на **групповых** встречах (не 1:1), формирует **подробный** контекст с таймкодами и **дописывает в `{slug}/meeting-context.md`**. Файл копится: старые встречи не удалять.

Связка со скиллом `1-1`: подготовка к 1:1 читает `meeting-context.md` **с даты последнего 1:1**. Более ранние блоки нужны, если ищешь кейс для ОС, которого нет в наблюдениях.

## Голосовые и текстовые команды

Скилл запускается простой фразой — имя человека достаточно:

- «обнови контекст по Диме»
- «собери что Дима говорил на встречах»
- «просканируй встречи по Гуминиченко»
- «обнови контекст по команде»
- «что было на встречах с Димой»

Если имя неоднозначно — уточнить. Если не указан период — см. правила отсечения ниже.

## Расположение

```
~/Downloads/*.txt                         — конспекты встреч
notes/teams/{гильдия}/{slug}/README.md    — карточка (поле Имя)
notes/teams/{гильдия}/{slug}/meeting-context.md — этот скилл пишет сюда
notes/meeting-context/                    — этот скилл
```

Подробности — в [reference.md](reference.md).

Вымышленный образец карточки и группового конспекта — `examples/teams/` и `examples/transcripts/` (от этой папки: `../../examples/`). Живые заметки — в `notes/teams/`.

## Общие правила

- **Только групповые встречи** — если участников (кроме Саидовой Камиллы) ровно 1 → пропустить.
- При **повторном прогоне** на ту же дату — **перезаписать** блок этой встречи (обновить содержимое).
- **Подробно, не телеграфно** — пользователь не помнит контекст встречи.
- Имя в конспекте сопоставлять с полем `**Имя** |` в файле человека.

## Сценарий 1: Один человек

### Шаги

1. Найти каталог человека `notes/teams/{гильдия}/{slug}/`, прочитать `Имя` в `README.md`.
2. Определить **дату отсечения:**
   - если пользователь просит «пересобери» / «ещё раз» — сканировать все конспекты с даты выхода или за 60 дней;
   - если секция есть и это инкремент — с даты последнего блока;
   - если секции нет — все конспекты с даты выхода или за 60 дней.
3. Запустить скрипт:

```bash
python3 notes/meeting-context/scripts/scan_transcripts.py \
  --person "Гуминиченко" \
  --since 18.05.2026
```

4. Для каждой встречи **прочитать конспект** (не только JSON скрипта) и оформить блок по шаблону ниже.
5. Записать/обновить в `{slug}/meeting-context.md` (дописывать новые встречи; ту же дату+встречу — перезаписать блок).
6. Показать резюме: сколько встреч, ссылки на файлы конспектов.

### Шаблон блока встречи

```markdown
### ДД.ММ.ГГГГ — [тип и тема встречи]

**Конспект:** `2026-06-26 1129 (MSK) 5542466754.txt`  
**Участников:** N | **Время начала встречи:** 11:29

**О чём встреча (кратко, 2–4 предложения):**
[Суть: какая задача/проблема обсуждалась, зачем собрались. Достаточно, чтобы вспомнить без конспекта.]

**Участники:** [ключевые имена кроме тимлида и целевого человека]

**Что говорил [Имя]:**

- `[52:07]` — [развёрнутая реплика: что спросил/предложил/уточнил, с контекстом]
- `[01:03:19]` — [следующая значимая реплика]
- ...

**Итог для тимлида:** [1–2 предложения: что это говорит о человеке — инициатива, вопросы, оценки, позиция]
```

### Требования к детализации

- **Каждая значимая реплика** — с таймкодом `[ЧЧ:ММ:СС]` для перехода в конспект.
- **Не писать** абстрактно («задал edge-case») — писать **что именно** спрашивал и **в каком контексте**.
- Группировать мелкие реплики под одним таймкодом, если это один поток мысли.
- Пропускать «спасибо», «понял», «ок» без содержания.
- **О чём встреча** — обязательный блок, даже если человек мало говорил.

### Название встречи

Формат: `[тип] — [тема / Jira]`.  
Примеры: `груминг — плашки акций (купон, text-code)`, `техсессия — фильтр брендов на PLP (лимит 2000)`.

## Сценарий 2: Вся команда

1. Список людей из `notes/teams/{гильдия}/*/README.md` (не `_template`, не чек-листы SA).
2. Пропустить, если в «Основная информация» статус не «в команде» (уволен / ИС завершён неуспешно) — если пользователь не назвала человека явно.
3. Сценарий 1 для каждого оставшегося.
4. Сводка: кто обновлён, сколько встреч, кого пропустили.

---

## Чего не делать

- Не писать телеграфные буллеты без контекста встречи.
- Не пропускать таймкоды у содержательных реплик.
- Не обрабатывать 1:1 как групповые.
- Не включать реплики тимлида в блок реплик человека.
