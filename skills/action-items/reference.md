# Action items — справочник

## Файл хранения

```
notes/leadership/kamilla-saidova.md
  └── ## Мои action items
```

Не путать с `notes/leadership/` разделами «Разбор 1:1» — там рефлексия, не задачи.

## Как распознавать обязательства тимлида

### В конспекте

**Спикер:** `Саидова Камилла` (любой вариант: голос 1, Зарифовна)

**Маркеры первого лица (обещание):**

- я сделаю / сделаю / могу сделать / в принципе сделаю
- я пришлю / отправлю / напишу / скину / дам
- я попрошу / запрошу / передам
- я подумаю и напишу
- давай я … / тогда я …
- буду делать / в любом случае пришлю

**Маркеры планирования (мягче — подтвердить):**

- надо бы / наверное сделаю / хочу / планирую
- лучше написать / можно …

**Не считать action item:**

- вопросы команде без обещания
- «ты сделаешь» / «Максим —» (это сотрудник)
- общие рассуждения без commitment
- follow-up **сотруднику** (если только «я пришлю follow-up» — **да**, это item тимлида)

### В файлах `teams/`

Строки `* Камилла — …` в `**Action items:**` или `**Договорённости:**` — кандидаты для синхронизации в `kamilla-saidova.md`, если ещё нет в «В работе».

При фиксации 1:1 скилл `1-1` уже пишет `Камилла —` в файл сотрудника; скилл `action-items` **дублирует в leadership**, не заменяет запись в teams.

## Типы встреч (поле «Источник»)

| Тип | Формат источника |
|-----|------------------|
| 1:1 | `1:1 [Имя] ДД.ММ` |
| Daily | `daily ДД.ММ` |
| Внешняя | `[тема/с кем] ДД.ММ` |
| Вручную | `вручную ДД.ММ` |
| Из teams | `teams/[файл] ДД.ММ` |

## Сопоставление сроков из речи

| В конспекте | В таблице |
|-------------|-----------|
| сегодня | `сегодня` или дата встречи |
| завтра | дата +1 |
| в пятницу | `пятница` или дата |
| на этой неделе | `эта неделя` |
| до отпуска / до 20.07 | конкретная дата |
| после созвона / когда пришлёт | `по факту` + статус `ждём` |
| следующая неделя | `след. неделя` |

## Дедупликация

Считать **одним item**, если совпадает смысл:

- «MM-группы» = «создать группы фронт/mobile/QA»
- «контакт Максима кластер-лиду» = «написать тимлидам на отпуск»

При обновлении — новый срок/статус в той же строке.

## Конспекты

Путь по умолчанию: `~/Downloads/*.txt`  
Дата: `Встреча проходила ДД.ММ.ГГГГ` или `YYYY-MM-DD` в имени файла.
