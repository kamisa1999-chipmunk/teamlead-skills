# Источники для Solution-research

Читать **на шаге понимания задачи**, до feature context и кода. Не читать в начале прогона «на всякий случай». Не меняет правила вариантов и формат пакета.

Способ чтения не привязан к конкретной локальной реализации. Skill одинаково работает, если Jira/Confluence доступны через MCP / connector / встроенный tool **или** через локальный Python CLI из репозитория.

## Выбор источника

Перед первым чтением Jira и перед первым чтением Confluence в этом прогоне — отдельно для каждой системы:

1. Использовать уже доступный в окружении источник (MCP, connector, встроенный tool), если он умеет прочитать нужный объект.
2. Если подходящего источника нет — локальный fallback из репозитория.

Не смешивать несколько источников одного артефакта без необходимости. Источник системы выбрать один раз за прогон и не менять без причины. Не перечитывать один артефакт повторно: после чтения свернуть в короткий summary.

Токены не читать и не показывать. Этим скиллом страницы, задачи и production code не изменять.

## Что принимает skill

Любой набор:

- Jira Story;
- Jira Analysis / SA Task;
- feature note (`notes/features/items/`);
- ссылка на Confluence;
- technical question;
- результат `feature-assessment` из этого или предыдущего диалога;
- текстовое описание;
- известные варианты и предпочтения пользователя;
- комбинация источников.

Не требовать полный набор. Не требовать заранее заполненную карту ответственности.

## Приоритет комментария пользователя

Комментарии и варианты этого прогона имеют высокий приоритет как `USER_INPUT` / `OPTION`.

Они **не** становятся `DECISION` сами по себе.

Плохо: `команда выбрала вариант A`.

Хорошо: `пользователь предлагает рассмотреть вариант A`.

## Jira / Story / SA Task

**Jira issue:** key, summary, description, type, status, links / parent / epic / subtasks, labels, components; comments — если помогают понять проблему, ограничения, уже предложенные варианты или принятые решения.

Story и Analysis — источники, не абсолютная истина и не выбранная архитектура.

Связанные технические задачи и предыдущие реализации — целевой поиск, не бесконечный discovery.

## Confluence

Искать по необходимости: текущую документацию, API specs, service pages, admin specs, ограничения, миграции, исторические решения, аналоги.

Найденная страница не считается автоматически актуальной. Конфликт документов — `OPEN_QUESTION`, не самостоятельный выбор «правильной» страницы.

## Feature notes

Канон — **папка** `notes/features/items/<nn>-<slug>/`, не россыпь файлов в `items/`. Правила пути и шаблоны — в `skeleton.md`.

Искать и папку, и одиночный `items/<nn>-<slug>.md` (его в конце прогона перенести в папку).

Если живая заметка уже есть:

- прочитать её;
- использовать историю решений, встреч, варианты, риски, ссылки;
- не копировать бизнес-контекст в `solution-research.md`;
- в research держать ссылку на живую заметку.

Не читать весь `features/` и весь `teams/`. Не читать карточки людей ради ownership.

Папки ещё нет — завести её в конце прогона вместе с живой заметкой. Это часть `solution-research`, не отдельная просьба пользователя.

## Неполные данные

Если выбранный MCP / connector / tool не отдаёт нужные поля:

- точечно добрать другим доступным способом (другой tool той же системы или local CLI fallback);
- не перечитывать уже полученные поля;
- если добрать нельзя — `OPEN_QUESTION` / `ASSUMPTION`, не выдавать отсутствие данных за факт.

Отсутствие поля в ответе источника ≠ «поля нет в системе». Нет доступа к коду — не выдумывать устройство системы.

Если обсуждение (Mattermost и т.п.) недоступно по ссылке — не выдумывать содержимое. Зафиксировать ссылку и при необходимости попросить фрагмент.

## Local CLI fallback

Только если подходящего MCP / connector / tool нет или им нельзя добрать нужные поля.

Jira:

```bash
python3 notes/jira/scripts/cli/get_issue.py CAT2-XXXX
python3 notes/jira/scripts/cli/search_issues.py --jql '...' --limit 20
```

Confluence по `pageId`:

```bash
python3 ~/.cursor/skills/sa-review/scripts/dump_confluence_page.py PAGE_ID
```

Поиск Confluence:

```bash
python3 ~/.cursor/skills/sa-spec/scripts/search_confluence.py --title "..."
python3 ~/.cursor/skills/sa-spec/scripts/search_confluence.py --cql 'space = BIZ AND title ~ "..."'
```

Скрипты не копировать в `solution-research`. Сырые выгрузки, если CLI их создаёт, — в `notes/jira/tmp/` (не в git). После прогона удалить файлы этого запуска. Не коммитить их.

Запись в Jira / Confluence этим скиллом не делать.
