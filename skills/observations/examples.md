# Примеры — observations

## Валидация: несколько раундов (эмоция не сдаёмся)

### Раунд 1

**Ты:** `@observations Андрей достал, слишком много говорит не по делу`

**Агент:**
```markdown
Слышу, что раздражает. Помогу записать так, чтобы потом можно было дать нормальную ОС.

**Пока собрали:** пока только ощущение, без деталей.

**Вопросы:**
1. Когда это было — сегодня, вчера? Какая встреча?
2. О чём должны были говорить?
3. Что именно он сказал или сделал — вспомни хотя бы один момент?
```

### Раунд 2 (ты всё ещё в эмоции)

**Ты:** «Ну мне всё равно не нравится, он опять лез не в своё»

**Агент:**
```markdown
Ок, «лез не в своё» — уже ближе. Давай докрутим.

**Пока собрали:**
- «не в своё» — уходил за рамки темы (уточним какой)

**Вопросы:**
1. Почему ты так думаешь — что он сказал, что было не по теме?
2. Это было один раз или несколько?
3. Что тебя задело сильнее всего в этот раз?
```

### Раунд 3 (факт почти готов)

**Ты:** «На груминге два раза про CI начал, а мы CAT оценивали»

**Агент:**
```markdown
**Черновик факта:**
03.07.2026 | рост | На груминге CAT-14411 дважды переводил обсуждение на CI, хотя повестка — оценка задачи | груминг 03.07 | обсудить на 1:1

Записываем?
```

## Валидация: эмоция → факт (короткий пример)

### Ввод (эмоциональный)

```
@observations Андрей достал на встрече, слишком много говорит не по делу
```

### Ответ агента (не записывает сразу)

```markdown
**Как сказала ты:**
«Андрей достал, слишком много говорит не по делу»

**Что вижу:** эмоция + обобщение. В таблицу так не запишу — потом самой будет неудобно давать ОС.

**Уточни, пожалуйста:**
1. Какая встреча, какая дата?
2. О чём была повестка?
3. Что именно он говорил — можешь вспомнить 1–2 момента?

**Черновик факта (заполним вместе):**
«На [встрече] [дата] Андрей [N] раз(а) переводил обсуждение на [тема], хотя повестка — [цель]»
```

### После ответа тимлида

```markdown
**Согласованный факт:**

03.07.2026 | рост | На груминге CAT-14411 дважды уходил в обсуждение CI-пайплайна, хотя повестка — оценка задачи | груминг 03.07 | обсудить на 1:1

Записать?
```

## Сценарий 2: Ad-hoc — уже с фактами

### Ввод

```
@observations запомни ситуацию с Димой: на дейли он предложил вынести обсуждение 
автотестов в отдельный тред, не стал тратить время команды — мне понравилось
```

### Валидация

Факт есть ✅ («предложил вынести в тред»). «Мне понравилось» — эмоция, в запись не идёт.

### Черновик

```markdown
07.07.2026 | позитив | На дейли предложил вынести обсуждение автотестов в отдельный тред, не продолжал тему на созвоне | daily | похвалить

Записать?
```

## Сценарий 1: Из конспекта

### Ввод

```
@observations зафиксируй наблюдение с встречи по Диме
~/Downloads/2026-07-03 1126 (MSK) 5542466754.txt
```

### Предложение (только факты из конспекта)

```markdown
## Наблюдения с встречи 03.07.2026 — Дмитрий Гуминиченко

1. **[позитив]** — `[39:04]` Спросил «какую проблему решаем этим усложнением логики»; `[39:37]` предложил два поля под две картинки → похвалить
2. **[рост]** — `[41:22]` Отметил, что сложная логика «порождает вопросы», привёл пример с галочкой «быстрый фильтр» → обсудить на 1:1

Подтверди: 1 да, 2 да / нет / поправь
```

### Если тимлид пишет «да, он всегда такой умник»

Агент: «„Всегда" — обобщение. Запишу пункт 1–2 как выше, без „умник"?»

## Когда пауза, а не отказ

### Ввод

```
@observations Мне кажется, Маша чем-то недовольна в последнее время
```

### Ответ (не «отклоняем», а копаем)

```markdown
Похоже на гипотезу — давай проверим.

**Вопросы:**
1. Что конкретно она сделала или сказала, что наводит на эту мысль?
2. Когда заметила — на какой встрече, в переписке?
3. Может, было что-то ещё — тон, реакция, отказ от задачи?

Если вспомним пример — запишем факт. Если нет — можем не записывать, а обсудить с ней на 1:1 напрямую.
```
