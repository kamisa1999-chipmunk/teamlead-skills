# Шаблон карточки человека

Каждый участник команды — **каталог** `teams/{гильдия}/{slug}/` с одинаковым набором файлов.  
`README.md` — рабочее оглавление. История не копится в README.

Не использовать этот файл как карточку: искать людей в `teams/{гильдия}/*/README.md`.

Чек-листы SA (`teams/sa/checklist-close-sa.md`) — не карточка человека.

## Файлы (у всех одинаково)

| Файл | Что внутри | Кто пишет |
|------|------------|-----------|
| `README.md` | Профиль, мотивация, краткие цели, открытые договорённости, ссылки | вручную / обновление профиля |
| `onboarding.md` | Чеклисты первых недель + итоги ИС | вручную; после ИС не дописывать чеклисты |
| `goals-is.md` | Цели на испытательный срок | вручную / 1:1 |
| `goals-pf.md` | Цели на полугодие / performance review | вручную / 1:1 |
| `1-1.md` | История 1:1 и блоки «Подготовка ДД.ММ.ГГГГ» | скилл `1-1` |
| `meeting-context.md` | Групповые встречи: копится целиком | скилл `meeting-context` |
| `observations.md` | Таблица наблюдений | скилл `observations` |
| `follow-up.md` | Follow-up и управленческий контур | скилл `1-1` сценарий 1в |
| `peers.md` | ОС коллег (peer feedback) | скилл `1-1` фиксация |
| `hr.md` | HR BP, решения по ИС, ИПР. Если нечего — `Нет записей.` | вручную |

**По роли, не заводить пустыми:** `sa-review.md` (индекс категорий) и `sa-review-CAT2-XXXX.md` (хронология задачи) — скилл `sa-review`, ревью тимлида.

## Правила накопления

- **`1-1.md`:** новые записи — в **начало** файла (свежие сверху). Остальную историю не перезаписывать.
- **Дописывать, не перезаписывать** историю в `observations.md`, `follow-up.md`, `peers.md`, `hr.md`.
- **meeting-context:** копится. При повторном прогоне на ту же дату+встречу — обновить блок, не дублировать.
- **Подготовка к 1:1:** из `meeting-context.md` читать блоки **с даты последнего состоявшегося 1:1**. Раньше — только если нужен кейс для ОС (позитив / риск), который не попал в наблюдения.
- В README **не** копировать полные 1:1, контекст встреч, follow-up, таблицы наблюдений, Jira-отчёты.
- Пустые чеклисты онбординга после первого месяца не держать в README.
- Плейсхолдер `### [Дата встречи]` в `1-1.md` не оставлять.
