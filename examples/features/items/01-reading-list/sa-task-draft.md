# SA-задача — черновик для Jira

Постановка задачи аналитику по Story [SHELF-120](https://jira.example/browse/SHELF-120). В Jira её создаёт `jira-write` после подтверждения. Решение здесь не проектируется.

### 1. Контекст

Story описывает именованный список на вебе. Избранное уже есть и остаётся. Пустой экран входит в историю, шаринг пустого списка не входит.

### 2. Цель анализа

Определить, где живёт список читателя и как страница книги в него пишет, не ломая избранное.

### 3. Что требуется проработать

- текущий контур избранного
- куда класть список: поле книги или отдельная сущность
- что видит веб в пустом и непустом списке
- какие клиенты этой задачей не задеты

### 4. Варианты / гипотезы для анализа

- поле на документе книги
- отдельное хранилище списков (предпочтение из research, не решение)

### 5. Документация / спецификации

### Найдено

- живая заметка фичи и solution-research в этой папке

### Не найдено / требуется проверить

- контракт избранного

### 6. Открытые вопросы

- один список или несколько

### 7. Критерий завершения

Понятно, какой контур меняется, что остаётся избранным, и какие спецификации надо писать. Архитектуру за команду задача не выбирает.
