# Story — черновик для Jira

Это текст description для DeliveryStory. Канон фичи — [01-reading-list.md](./01-reading-list.md). В Jira его кладёт скилл `jira-write` после подтверждения.

*Контекст / проблема*
На карточке книги есть только сердечко «избранное». Читатель не может собрать именованный список. В макете нарисована полка с книгами и не нарисован пустой список.

*Цель*
Со страницы книги читатель добавляет книгу в свой список и понимает, что список пуст, пока книг нет.

*Ожидаемое поведение*
- На карточке книги есть действие «в список». Сердечко остаётся.
- Пустой список показывает текст «здесь появятся книги» и кнопку создания.
- Список с книгами показывает полку.

*Scope*
Веб, страница книги и экран списка.

*Out of scope*
- шаринг пустого списка
- замена избранного
- iOS и Android

*Ограничения / зависимости*
Пустое состояние нужно в макете до оценки.

*Идеи / гипотезы для анализа*
Есть предпочтение посмотреть отдельное хранилище списков, а не поле на книге. Это не выбранное решение.

*Открытые вопросы*
Один список у читателя или несколько. Non-blocking: Story можно завести и без этого.
